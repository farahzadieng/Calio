- Implemented adult reference values use National Academies Appendix J, 2019, tables for recommended/adequate amounts and tolerable upper limits: https://www.nationalacademies.org/read/25353/chapter/28. The checked-in extract preserves age and physiology group, RDA/AI/UL and supplement-specific magnesium UL. g-to-mg and µg-to-mg conversions use the canonical units. Mixed-form vitamin A, folate, niacin and vitamin E, food-plus-drink water, protein by body mass, and energy-dependent reference ranges are withheld where the supplied measurement contracts cannot establish comparable scope or chemical basis.
- Vitamin D IU conversion is source-specific (1 µg = 40 IU): https://ods.od.nih.gov/factsheets/VitaminD-HealthProfessional/.
