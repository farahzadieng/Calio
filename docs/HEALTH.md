# Apple Health: read-only Shortcut bridge

No HealthKit web API or native app; no write actions. Existing user-built Shortcut is authoritative; ask exact name, output/clipboard behavior and units before wiring. Do not make user rebuild it unnecessarily. Four fields only: Resting_Energy (kcal), Active_Energy (kcal), Steps (count), Distance (km; confirm). Existing query about 14 days returns up to 15 inclusive dates. Accept variable lengths, not fixed 14. Local manual paste always works without invoking Clipboard API. Launch user-initiated `shortcuts://run-shortcut?name=<encoded>` only after exact name is provided; return/callback not guaranteed; verify installed iPhone Safari and standalone. Clipboard requires permission/user gesture; offer paste field and Import button, no background reads. Do not fake auto sync.

Exact input grammar (not JSON): named blocks Dates, Resting_Energy, Active_Energy, Steps, Distance, `{` newline separated values `}`, comma separators, optional trailing comma. Example fixture in fixtures/health-valid.txt. Parse anchored grammar, normalize CRLF/whitespace, exact keys, reject duplicates/unknown/missing blocks, unequal lengths, invalid dates, malformed/negative/nonfinite values, noninteger steps, duplicate dates. Explicit missing values may be allowed only if confirmed Shortcut emits them; preserve positional alignment. No eval. Validate entire payload before atomic upsert. Date record contains nullable values and status. Zero energy with activity/steps present is suspicious; retain raw value/status, not eligible for balance. Zero steps/distance can be valid. Tiny resting energy and current day partial should be flagged (threshold documented and approved); never classify zero energy as true full day automatically. Missing field may preserve previous valid value; suspicious zero must not overwrite valid earlier complete value; keep diagnostic and provenance. New valid values supersede old valid values per date. Never delete outside import window. Repeat same payload idempotent. Missing dates remain absent; don't synthesize zeros. Health import not AI input. Daily energy sum only when both valid and complete; compare with matching logged intake dates. Report displays coverage and stale/partial labels.

Weekly pipeline: process pending notes -> ask for sync if fresh import missing for due period -> import -> validate coverage -> local stats -> weekly report. User action needed to run shortcut/paste; if declines, keep pending or explicitly allow limited report with owner approval, not fully synced. Do not claim ready until saved report exists. Test launch, unavailable shortcut, clipboard denial, manual paste, partial dates, malformed format, replay, corrected days, offline and return to PWA.
