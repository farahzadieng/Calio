# Product specification

## Purpose
Write daily; understand weekly. Calio makes nutrition and activity understandable without forcing the user to count calories or fill meal forms. Personal adult wellness and weight tracking, not a medical device. Local raw notes remain editable forever.

## Onboarding
First name, age, height cm, weight kg, activity level (sedentary/light/moderate/high/very high), goal (understand/maintain/lose/gain), language, calendar, timezone. Ask physiological reference variable for REE/DRI or allow skip (no false precise estimates). No AI needed; calculate local REE/TDEE with explicit approximation. Show privacy consent before real AI. Invite Health setup; skip possible; never block journal. Use custom multi-step questionnaire with accessible validation. Profile can be updated without changing historical reference snapshots. Adult-only estimates; pregnancy/lactation/medical contexts need qualified guidance and no automated weight target.

## Main interaction
Default screen: date and free-text note, Save; chronological notes with edit/delete, date navigation, visible unprocessed status only when needed, manual Analyze button, one understated weekly message. Do not place a calorie dashboard on this screen. No obligatory meal category, grams, timing, photo, confirmation. Optional time from creation and symptom notes (e.g. poor sleep), never assume absence means symptom-free. Save immediately offline. Dates editable, past notes allowed. Delete/edit invalidates dependent reports; preserve raw revision history only if explicitly approved or necessary for audit; allow deletion from local DB.

## Navigation (proposed, confirm if owner prefers otherwise)
Journal / Drinks / Insights / Profile. The Drinks page has one-tap presets for water (250 mL), coffee (150 mL), tea (200 mL) and alcohol-free beer (250 mL). Each resulting entry can be edited. Custom volume, type, strength and known caffeine remain available. Avoid double counting same drink in notes and drinks; link or user-resolve clear duplicate only. Journal has a direct supplement shortcut for an existing product or defining and logging a compound supplement on the selected journal date. The Profile supplements page also supports independent product setup and consumption logging. Record serving count, serving unit and label composition. No automatic consumption. Never infer dosage; label per serving, multiply by logged count, preserve IU and conversion only when nutrient-specific verified. Food and supplement totals separate and combined. Unknown caffeine or nutrient amount stays null.

## Weekly cycle
Automatic processing once per completed seven-day interval on first foreground visit with network and consent. No calls on each entry/day. Manual batch available, processes selected pending notes without triggering extra automatic report. Process older missed windows in order, batch within limits; idempotent period/revision IDs. Require fresh Health import before final weekly analysis; if missing show action message, preserve pending state, don't say ready. Retry after sync or connectivity with no duplicate charges where feasible. Once validated report persisted show one "Your weekly report is ready" message. Review only high-impact uncertainty; show optional correction in details. Do not ask for routine confirmation.

## Insights
Daily cards chronological: intake, resting+active expenditure, balance only when data adequate, steps, distance, protein/carbs/total fat/sugar/fiber/sodium and salt equivalent, drink/supplement totals and uncertainty. Tap for full 39 nutrients. Weekly aggregate: totals and daily averages, nutrient reference coverage, limit exceedances, food vs supplement, measured vs estimated energy, data gaps. Missing days not zero; chart gaps, explain denominators. Historical periods browse, no daily AI report. Weekly AI editorial report: energy/activity, what went well, low estimated intakes and excess, patterns, plausible lifestyle associations, practical culturally relevant changes, uncertainty, data gaps, and when to seek professional advice. No claim vitamin C caused sleep issues or that steps measure sitting; user-reported symptoms optional. No moralized food scores.

## Monthly
At chosen monthly boundary ask current weight, compare against initial/end weights and matched date energy balance. Display observed and estimated change with model/version, coverage and uncertainty; no prediction when data inadequate. Weight model unresolved: user requested 2600 kcal/kg, evidence-based rough 7700 not a guarantee. Ask user; if 2600 chosen keep explicitly custom/unvalidated comparison only, not target or medical advice. If difference exceeds owner-approved threshold or data is insufficient, explain and offer external AI prompt (monthly template). No automatic external send. User previews and copies, excludes personal identifiers by default. Include detailed food logs/summary, nutrient gaps, activity, supplements, reported symptoms, actual/estimated change, assumptions and limitations. External AI may discuss supplement considerations safely; no automatic prescriptions.

## Settings
Language independently of calendar, timezone, light/dark/system, accessibility, weight/goals, AI provider status/consent/test, Health Shortcut name/test/import, food library view/search/edit/import/export, full backup/export/import, diagnostics/test messages, clear demo data, delete local data with custom confirmation. User can inspect cached food and portion evidence, correct entries without AI when possible. Do not store secrets in backup.
