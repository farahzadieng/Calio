# Backup, import and privacy

Settings exposes independent Food Library export/import (JSON with foods, aliases, portions, evidence; CSV for editable flat references with explicit units) and Full Backup/Restore (all DB entities, profile, logs, notes, Health, weights, supplements, settings, reports, messages, pending jobs, library, schema versions). JSON canonical envelope format `calio.full-backup` or `calio.food-library`, schemaVersion, exportedAt, appVersion, data; validate all rows with entity schemas, references, unique ids, dates, units, numeric bounds, max size and version. Never include API keys, auth tokens, private debug dumps, cached secrets. User data exported locally; warn unencrypted file contains personal health data. Optional encryption only with approved design. No remote autosync. CSV escape formula-injection cells for spreadsheet usage; import treat cells as literal, no formula execution. Blank numeric = null, 0 preserved. For CSV metadata/evidence use serialized JSON column or companion JSON, not silently lost.

Restore flow: custom file selection button (browser's security-controlled file chooser unavoidable), dry-run preview counts/errors/version, choose merge or replace, explicit confirmation for replace, pre-restore export/snapshot, migration in staging transaction, commit atomic; failed import leaves old DB unchanged. Merge stable IDs and conflict report; no silent overwrites, duplicate same file idempotent. After restore rederive totals, expire leases, do not auto-resend paid requests or restore ready claims with stale inputs. Food-only import never touches journal or Health. Reject mismatched type, future version, invalid data, unsafe text, orphan links; render text escaped. Test full roundtrip, merge conflicts, rollback, empty library, offline, corrupted file.

AI opt-in explains data sent and provider retention policy (verify selected provider). Only food text necessary to extract, food-only queries for research, weekly structured aggregates + relevant context without identifiers, monthly prompt local copy. Secrets Worker environment, auth even for personal deployment, rate/budget limits, avoid CORS wildcard, no raw payload logs. HTTPS; CSP and restrictive permissions, sanitize URLs and Markdown, no dangerouslySetInnerHTML for AI/user content, protect import against prototype pollution and excessive size. Clipboard explicit action. Diagnostics redacted, no PII/key/full logs. User can delete data and revoke consent; delete local records and caches, explain external provider retention cannot be undone. Browser storage not guaranteed; remind backup without nagging.
