# Runtime prompt contract
All `.md` prompts are trusted system instructions. Inject inputs separately as serialized JSON user data, never concatenate raw user text into system instructions. Use exact schemas in `../schemas/`; server and client validate, reject extra keys, check semantic constraints (IDs, units, nonfinite, evidence, confidence, ranges). Request JSON structured output if supported, otherwise parse exact JSON only, one bounded repair with validation error, no arbitrary code execution. Actual search tool required for research. Log usage only, no private content. Templates versioned v1; no user PII in food research. Monthly prompt is local template for copy, not an automatic API request. IDs in prompts refer to actual local input references.
