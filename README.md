# Calio | کالیو

کالیو یک دفترچهٔ شخصی تغذیه و فعالیت است که به‌صورت PWA نصب می‌شود. ثبت یادداشت، نوشیدنی، مکمل و وزن در مرورگر انجام می‌شود و داده‌ها روی همان دستگاه می‌مانند. رابط فارسی و انگلیسی، تقویم شمسی و میلادی، حالت روشن و تیره و کار آفلاین را پشتیبانی می‌کند.

نشانی برنامه‌ریزی‌شدهٔ انتشار [calio.luminiastudio.ir](https://calio.luminiastudio.ir/) است. نسخهٔ وب در این نشانی هنوز منتشر نشده است.

## امکانات

- دفترچهٔ روزانه با ثبت آزاد خوراک، ثبت یک‌لمسی نوشیدنی و ثبت دوز مکمل‌های ساده و ترکیبی
- نمودار روزانه، هفتگی و ماهانهٔ انرژی دریافتی و مصرفی، درشت‌مغذی‌ها، قدم، مسافت و نوشیدنی
- ورود محلی اطلاعات Apple Health با Shortcut خواندنی `HealthKit-Bridge` و همگام‌سازی موردنیاز برای تحلیل هفتگی
- جدول آفلاین کالری خوراکی‌های ایرانی، کتابخانهٔ شخصی، تحلیل کالری با API یا کپی پرامپت و ورود پاسخ JSON
- پشتیبان کامل و واردکردن و خروجی گرفتن جداگانهٔ کتابخانه با JSON و CSV

## معماری

| بخش | فناوری و مسئولیت |
| --- | --- |
| رابط | React، TypeScript و Vite در `src/app` با مسیرهای React Router و کنترل‌های Base UI |
| طراحی | سیستم Japandi در `src/styles/calio.css` با فونت محلی بنیاد کودک، تم روشن و تیره، RTL/LTR و اسلاید جهت‌دار |
| داده و منطق | Dexie و IndexedDB در `src/db`، محاسبات تغذیه و تقویم در `src/domain` و جریان‌های ثبت، گزارش و پشتیبان در `src/services` |
| نصب و آفلاین | Workbox در `src/sw.ts` برای پوسته، فونت و تصاویر |
| تحلیل اختیاری | درگاه Node.js در `server` با API سازگار با OpenAI، رضایت کاربر، اعتبارسنجی Zod و قراردادهای JSON در `schemas` |

ثبت محلی به حساب یا سرویس تحلیل نیاز ندارد. درگاه هم‌مبدأ تنها پس از تنظیم اتصال و رضایت کاربر، درخواست تحلیل را به ارائه‌دهنده می‌فرستد. مدل تحلیل و مدل جست‌وجوی کالری جداگانه قابل تنظیم‌اند. کلیدها در سرویس محلی نگه‌داری می‌شوند و در بستهٔ مرورگر یا بکاپ قرار نمی‌گیرند. [جزئیات معماری](docs/ARCHITECTURE.md)

## اجرای محلی

نسخهٔ Node.js باید با بخش `engines` در `package.json` سازگار باشد.

```sh
npm ci
npm run build
npm run build:server
npm start
```

برنامه، تنظیمات اتصال و سرویس آفلاین را در [http://127.0.0.1:4173](http://127.0.0.1:4173/) باز کنید. برای توسعهٔ رابط از `npm run dev` استفاده کنید. راه‌اندازی روی آیفون به HTTPS نیاز دارد. [راهنمای استقرار](docs/DEPLOYMENT.md)

## آزمون و نگه‌داری

```sh
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
npm run build:server
npx playwright install chromium webkit
npm run test:e2e
```

برای استفاده از Chrome نصب‌شده روی macOS از `CALIO_CHROMIUM_CHANNEL=chrome npm run test:e2e` استفاده کنید.
